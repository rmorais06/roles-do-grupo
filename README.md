# roles-do-grupo
Rolês do Grupo — Streamlit
Rodar no computador
Instale Python 3.10 ou superior.
Abra o terminal na pasta do projeto.
Instale as dependências:
```bash
pip install -r requirements.txt
```
Inicie o app:
```bash
streamlit run app.py
```
O navegador abrirá a página do formulário. As respostas são guardadas em `dados/respostas_grupo.csv`. Uma nova resposta com o mesmo nome substitui a anterior.
